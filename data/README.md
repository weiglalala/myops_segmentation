# Dataset

This project uses the **MyoPS 2020 Challenge** dataset.

## Download

1. Register at the MyoPS 2020 Grand Challenge (https://myops20.grand-challenge.org/)
2. Download the training and test data
3. Place files in this directory following the structure below

## Expected Structure

`
data/
├── train25/
│   ├── train25_myops_gd/          # Ground truth labels
│   └── ...nii.gz                  # Multi-sequence MRI volumes
├── train25_augmented/             # Generated by augment_offline.py (optional)
└── test20/
    ├── test20_myops_gd/           # Ground truth labels
    └── ...nii.gz                  # Multi-sequence MRI volumes
`

## Modalities

Each case contains three MRI sequences:
- **C0 (bSSFP)**: Balanced steady-state free precession - cardiac anatomy
- **T2**: T2-weighted - sensitive to edema
- **LGE**: Late gadolinium enhancement - sensitive to scar

## Labels

| Value | Class |
|-------|-------|
| 0 | Background |
| 200 | Normal myocardium |
| 500 | LV blood pool |
| 600 | RV blood pool |
| 1220 | Edema |
| 2221 | Scar |
