# Data Directory

This project uses the **MyoPS 2020 Challenge** dataset.

## Download

The dataset can be obtained from the official challenge website:
- [MyoPS 2020 Challenge](https://myops20.grand-challenge.org/)

## Expected Structure

```
data/
├── train/
│   ├── Case3001/
│   │   ├── Case3001_C0.nii.gz      # bSSFP (cine MRI)
│   │   ├── Case3001_T2.nii.gz      # T2-weighted MRI
│   │   ├── Case3001_LGE.nii.gz     # Late Gadolinium Enhancement MRI
│   │   └── Case3001_gd.nii.gz      # Ground truth segmentation
│   ├── Case3002/
│   │   └── ...
│   └── Case3025/
├── test/
│   ├── Case3026/
│   │   └── ...
│   └── Case3045/
└── train_augmented/    # Generated by augment_offline.py (optional)
```

## Notes

- 25 training cases (Case3001-Case3025) with ground truth labels
- 20 test cases (Case3026-Case3045) with ground truth labels
- Each case contains 3 MRI modalities in NIfTI format
