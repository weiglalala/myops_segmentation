# Dataset

This project uses the **MyoPS 2020 Challenge** dataset.

## Download

1. Register at the MyoPS 2020 Grand Challenge ([MyoPS 2020](https://zmiclab.github.io/zxh/0/myops20/index.html))
2. Download the training and test data
3. Place files in this directory following the structure below

## Expected Structure

```
data/
├── train/                         # 25 training cases
│   ├── Case3001/
│   │   ├── Case3001_C0.nii.gz    # bSSFP modality
│   │   ├── Case3001_T2.nii.gz    # T2-weighted modality
│   │   ├── Case3001_LGE.nii.gz   # Late gadolinium enhancement
│   │   └── Case3001_gd.nii.gz    # Ground truth labels
│   ├── Case3002/
│   │   └── ...
│   └── Case3025/
│       └── ...
├── test/                          # 20 test cases
│   ├── Case3026/
│   │   ├── Case3026_C0.nii.gz
│   │   ├── Case3026_T2.nii.gz
│   │   ├── Case3026_LGE.nii.gz
│   │   └── Case3026_gd.nii.gz
│   └── ...

    │   └── ...
    └── ...
```

## Modalities

Each case contains three MRI sequences:
- **C0 (bSSFP)**: Balanced steady-state free precession - cardiac anatomy
- **T2**: T2-weighted - sensitive to edema
- **LGE**: Late gadolinium enhancement - sensitive to scar

## Labels

| Value | Class |
|-------|-------|
| 0 | Background |
| 200 | Normal myocardium |
| 500 | LV blood pool |
| 600 | RV blood pool |
| 1220 | Edema |
| 2221 | Scar |
